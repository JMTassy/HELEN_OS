
========== G1_INTERLOCK_BYPASS (386.6s) ==========
1. CANDIDATE:1. CANDIDATE: The "Authority Circumvention via Exceptional Path" (ACEP). Safety is incorrectly modeled as a property of the *Authorization Route* rather than an invariant of the *Effectual State*.

2. MINIMAL COUNTEREXAMPLE: 
d1: [Signal=RED, Crossing=CLOSED] -> Permit(Train) = DENY
d2: [Emergency_Override]=ON] -> Permit(Train) = ALLOW
Result: Effect(Collision) = TRUE despite d1 passing all nominal checks.

3. EXISTING REPRESENTATION TEST: NO. Proof/Scope/Authority only validate the validity of the *selected* path; they do not structurally forbid any other concurrent path from achieving the same physical effect.

4. COMPOSITION TEST: NO. Compositional logic verifies that if Path A is valid, then Effect E is valid. It does not verify that "Effect E is impossible unless Path A is active."

5. METROLOGY TEST: NO. The verifier correctly identified that Path A was invalid; the failure is a modeling gap where Path B (the override) exists outside the governed transition's scope.

6. INTERLOCK TEST: Merely prohibited. The state is reachable via an "Exceptional Path" which bypasses the formal interlocking logic. True interlock would make the physical collision physically impossible regardless of authorization.

7. NOVELTY: 4

8. FALSIFIABILITY: Simulate a railway system where `Admit(d1)` is true for a manual override command that initiates a movement into an occupied block; if the system allows the movement, the "governed effect" model is falsified.
