# HELEN OS — Canonical Palette

Locked. Do not deviate without explicit operator instruction.

| Token | Hex | Use |
|---|---|---|
| black | `#060608` | Canvas, page background |
| surface | `#0d0d10` | Panel backgrounds |
| graphite | `#141418` | Hover states |
| border | `#1e1e24` | Dividers, card borders |
| off-white | `#e4dfd4` | Primary text (warm, archival) |
| silver | `#78756f` | Secondary text, labels, dim data |
| silver-hi | `#9e9a94` | Mid-weight metadata |
| signal | `#c49a3c` | **One signal color.** Kernel nodes, sovereign badge, receipt hashes, selection rings, orbital ring, avatar border |

**No other colors.** No gradients. No rainbow accents. No SaaS blues.

Signal amber is used sparingly — it marks what is sovereign, verified, or selected.

## Typography

| Role | Stack |
|---|---|
| Title / labels | `Georgia, 'Times New Roman', serif` |
| UI / body | `-apple-system, BlinkMacSystemFont, 'Helvetica Neue', sans-serif` |
| Data / hash / mono | `'SF Mono', 'Fira Code', monospace` |

Weights: normal and 600 only. Monospace for all hashes, scores, timestamps.
