# HELEN Avatar Placement Rules

Source of truth: `oracle_town/skills/ops/airi_helen_avatar/SKILL.md`

## Short version

HELEN must be structural, never decorative.

Current canonical placement: gravitational center of semantic constellation.
Current secondary placement: 36px witness thumbnail in node detail panel.

She witnesses. MAYOR certifies. HELEN never ships.

## What "witness" means

When a user clicks a semantic node, HELEN says:

> I witness this EVENT.
> I witness this EPOCH.
> I witness this ACTION.

This is not a claim. It is an observation. The avatar becomes part of the OS interaction loop — she responds to the field, not to the user directly.

## What breaks the rule

- Putting her in a corner as a logo
- Using her face as a loading spinner
- Making her wave or talk in response to UI events (she observes, she does not perform)
- Removing her and adding generic AI hologram iconography
