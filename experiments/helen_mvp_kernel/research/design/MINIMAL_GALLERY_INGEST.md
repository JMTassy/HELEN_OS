## CANDIDATE STYLE AXIOMS (for HELEN L1 surfaces — CANDIDATE, not canon)

These enter the design lane as HYPOTHESES to be checked against the
primary corpus when the local lane fetches it:

    D1  every element carries a justification or it is removed —
        the design twin of "every claim carries a witness"
    D2  whitespace is the default state; content is the exception
        admitted into it — the visual Gamma
    D3  one typeface family, few weights; hierarchy by size and
        space, never by decoration
    D4  palette ≤ 3 colors + neutrals; color is a signal, not a skin
    D5  motion only when it carries state information (the
        NON_DELTAS of animation: what did NOT move is part of the
        design)
    D6  the receipt aesthetic: a page should answer what it is,
        what it does, and what it deliberately omits

Convergence note: D1-D6 are consistent with the existing
helen-design-motion doctrine (Uzik reference, sober claims, rich
form) — the gallery is a corroborating reference for a style HELEN
already holds, not a new master.
