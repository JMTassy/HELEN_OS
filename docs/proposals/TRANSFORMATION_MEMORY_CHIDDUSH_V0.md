## The three-archive stack

Ephemera collections expose ARTIFACTS (A). The ATF specimen book exposes
GRAPHIC GRAMMAR (G). Material-Archiv exposes MATTER, PROCESS,
CONSTRUCTION (M, P, K). Together: A = F(M, P, K, G, C) — a physical
artifact cannot be generated from symbolic primitives alone; there must
be a substrate. The prior "design compiler" chiddush was incomplete.

## Material = state + affordance space

A material is not a label on an object. It is a knowledge object with
transformation affordances: M --P--> M′, and (M₁…Mₙ) --K--> A. Which
verbs apply (cut, fold, print, coat, laminate, emboss) depends on the
material-process pair. Archives that store `material = "paper"` store a
noun and discard the causal structure.

## The core chiddush — archive verbs, not only nouns

Traditional archive: NOUNS. Material-Archiv's reported architecture adds
VERBS (Verfahren) and RELATIONS (Konstruktionen, Anwendungen). Schema:

    ENTITY + TRANSFORMATION + CONSTRAINT + RESULT   — not ENTITY + metadata.

Generalized: stop thinking in sets 𝒜 = {a₁…aₙ}; think in a category
𝒞 = (Obj, Mor) — objects: materials, primitives, constructions,
artifacts, states; morphisms: cut, print, join, coat, compose, use,
degrade, repair, recycle, archive.

    THE ARCHIVE SHOULD NOT ONLY REMEMBER THINGS.
    IT SHOULD REMEMBER THINGS + TRANSFORMATIONS BETWEEN THINGS.

## Transformational provenance and material memory

Provenance should answer "what happened to matter": M₀ --p₁--> M₁
--p₂--> … --> A, plus measurements and context — not just collection,
producer, date. And matter partially records its own history:
Mₜ = F(M₀, H₀:ₜ) — grain, patina, corrosion, wear. Not perfect memory,
not invertible, but real. Consequence for HELEN:

    documented provenance  vs  material evidence
    — two INDEPENDENT witnesses of the same trajectory, which may
    agree or conflict. Matter is a second seat.

Conflict between them is a cross-seat signal (Bayesian-Witness input,
never permission). This is the physical-world twin of P_global ⟺ ⋀ P_s.
