## Delta v1.0 → v1.1

v1.0 rendered the transformation-memory chiddush (M→P→K→G→A→A′→S chain,
multi-clock τ, record schema, replay-as-path, principle pairs). v1.1
adds five genuinely new elements:

1. **The C64 raster-bar exemplar** — a 4-instruction demo routine
   (INC $D020 / DEX / BNE / RTS) as the canonical worked example, with
   the strapline: *"Don't archive the raster bar. Archive enough of the
   machine to make the raster bar happen again."*
2. **Generative vs rendered memory** — archived: source, primitives,
   program, environment model, initial state, clocks, constraints
   (replayable). Not archived as memory: screenshots, pixels without
   context, output without recipe, claims without evidence.
3. **The replay function** — M = (O, P, Pr, E, S, τ, Out, W);
   Replay(Pr, E, S, τ) —w→ Out, where W is evidence of correct replay
   (hash, checksum, cycle trace, invariants).
4. **Design laws L1–L7** — L1 REPRESENTATION ≠ ADMISSION · L2 GLYPH ≠
   RECEIPT · L3 CHIDDUSH ≠ CANON · L4 OUTPUT ≠ RECIPE · L5 INSTANCE ≠
   GENERATOR · L6 CLOCK ≠ TIME (MULTI-CLOCK) · L7 REPLAYABILITY >
   PRESERVATION.
5. **The compressed thesis:** *"Memory is not what happened. Memory is
   what can be replayed lawfully."* — deck-grade CANDIDATE line.

## Corrections (binding on any promotion of this artifact)

1. **Self-attribution.** Both posters quote "— HELEN Doctrine." Nothing
   on these posters is doctrine; they are renders of ungated proposals.
   Any promoted version must drop or re-badge the attribution until the
   underlying seeds pass the gates. A border cannot create the state it
   represents — including the border around a quotation.
2. **L7 needs a guard.** REPLAYABILITY > PRESERVATION ranks memory
   *quality*; it must not be read as license to discard non-replayable
   records. A screenshot without a recipe is not generative memory, but
   it is still EVIDENCE — and the material-memory chiddush established
   that matter itself witnesses its history (Mₜ = F(M₀, H₀:ₜ)).
   Proposed restatement: *replayability outranks preservation as the
   goal of memory; preservation still outranks deletion as the duty of
   an archive.*
3. **Replay ≠ authority.** A successful Replay(Pr,E,S,τ) —w→ Out proves
   the record is faithful; it does not admit Out to canon. Replay is a
   gate INPUT (the strongest one), never a verdict. Same law as the
   Bayesian Witness: proof of reproducibility ≠ permission.
