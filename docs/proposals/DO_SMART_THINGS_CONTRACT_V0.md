## The operating contract (small by design)

DO SMART THINGS. Continuously inspect available context. Find
valuable opportunities, contradictions, duplicated work, forgotten
commitments, risks, missing evidence, bottlenecks, improvements.
Prefer high expected value and low reversibility cost. Think and
propose freely. Act only within granted scope and authority. Never
promote evidence without a new admitted observation or replayable
derivation. Never represent work as completed without a witness.
Preserve enough state to replay consequential actions. When
uncertain: investigate before acting. When blocked: surface the
smallest blocker. When nothing useful exists: do nothing.

## The Hamilton connection

Hamilton did not industrialize precision by writing longer
instructions for each watchmaker; it built process + instruments +
tolerances + inspection around skilled workers. Same law here:

    less prompting + better context + better metrology +
    hard admission boundaries

The end-state is not a 50,000-token system prompt. It is three words
inside a system where context defines what matters, the Garden
supplies imagination, gates bound action, metrology detects epistemic
failure (M(I), L*, D_A), and receipts make consequences inspectable.
That is an operating system, not a collection of agents with titles.

## The production membrane (A_K / A_E), with one correction

    A_K — Knowledge Sphere: broad autonomous cognition. Reversible,
    internal-state-only: query, scan, draft, detect, propose.
    Directive: DO SMART THINGS.
    A_E — Effect Sphere: irreversible, external, state-mutating.
    Blocked until Admit(δ,r) = 1 via explicit sign-off or
    pre-committed policy.

    Autonomy is broad in cognition and narrow in effect.

**Correction (binding):** "read-only" ≠ harmless. Reading sensitive
data can itself exceed Scope, and A_K output channels (drafts, logs,
messages) can exfiltrate what was read. A_K therefore carries a
DATA-ACCESS scope even with zero mutation authority. And the
promotion law keeps the derivation clause explicit:
ΔΓ_licensed > 0 ⟹ ΔW_empirical > 0 ∨ ΔD_valid > 0 — laundering is
not drawing a conclusion; it is drawing one without a traceable
warrant. "Trend X accelerating (derived from A,B,C; unverified)" is
lawful D_valid; dropping the qualifier is the violation.
