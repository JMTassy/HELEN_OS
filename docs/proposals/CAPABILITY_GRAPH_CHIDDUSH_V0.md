## The refinement

    LOST DESIGN COMPILER  →  LOST CAPABILITY GRAPH
    (the ATF design compiler remains a valid subgraph: 𝒞_design ⊂ 𝔾_capability)

ATF modeled one foundry's compiler 𝒞ₜ:(Σₜ,Rₜ,Cₜ)→𝒫ₜ. The Exhibition
requires an ecosystem 𝕔ₜ = {𝒞ₜ⁽¹⁾…𝒞ₜ⁽ⁿ⁾}: foundry (metal→type), printer
(type+ink+paper→print), textile (fibre+process→fabric), and so on. The
catalogue is partial documentary evidence of MATERIAL → MACHINE →
PROCESS → PRIMITIVE → COMPOSITION → PRODUCT — an industrial generative
ecosystem, observed once, in one building.

## The new primitive: CAPABILITY (and its epistemic split)

ATF taught TYPE ≠ TOKEN. The Exhibition adds OBJECT ≠ CAPABILITY, and
the skill now enforces the three-way split:

    OBSERVED OBJECT ≠ DECLARED CAPABILITY ≠ INFERRED CAPABILITY

Exhibited(m,o) is evidence; CapableOf(m,p) needs explicit description;
CapableOf(m, everything-morphologically-similar) is never automatic.

## The graph, evidence-qualified

G₁₈₅₁ = (V,E), V = M⊔A⊔P⊔T⊔O⊔L (materials, actors, processes, tools,
objects, locations); edges manufactured/exhibited/supports/acts-on/
produces — every edge e = (u, r, v, π, ε) with provenance π and
ε ∈ {explicit, derived, inferred, hypothesized}. Substantially more
defensible than embeddings over a Victorian catalogue.

## Possibility gains geography and actors

    𝒫(t, g, a):  Known(p,t) ⇏ Accessible(p,g,t) ⇏ EconomicallyViable(p,g,t)

    conceivable ⊇ technically-known ⊇ locally-accessible ⊇
    economically-feasible ⊇ produced ⊇ surviving

Style becomes partly testable: STYLE ≈ SELECTION | CAPABILITY — a
selection distribution over an affordance space, conditioned on
P(o | Σ, R, M, T, K, g, c). Not a definition of artistic style; a
testable component of one.

## The correction that matters: negative evidence

Earlier model: available-but-absent ornament = negative evidence. Wrong
as stated. Absence is informative only when exposure opportunity is
established:

    absence + availability + accessibility + sampling adequacy
    ⇒ potential negative evidence   (each term required)

An ornament existing in Philadelphia says nothing about its absence
from Malaysian wrappers unless Malaysian printers could acquire it and
the surviving sample is adequate. This guard is now baked into the
chiddush-archive skill (§6).

## CAPABILITY RECEIPT — the architectural chiddush

An artifact receipt attests ∃o: Observed(o). A capability receipt
attests that a —P,C→ o was actually demonstrated:

    R_cap = (a, M, T, P, O, C, t, g, π, w)

with the hard bound **R_cap ⇏ unbounded capability** — a witnessed
capability has a domain (process, material, scale, time, place).
HELEN-side note: this is the receipt family a governed agent economy
needs — "this agent demonstrably did X under conditions C" rather than
"this agent can do X." Sovereign-adjacent as schema; proposal only,
MAYOR-routed.

## The inverse problem (the science)

    𝔾ₜ —selection→ 𝒪ₜ —survival→ 𝒜ₜ ;  the archive gives 𝒜ₜ;
    the problem is 𝒜ₜ → 𝔾̂ₜ under uncertainty and provenance.

Falsification criteria: a reconstruction that predicts historically
impossible processes, unavailable materials, impossible chronology, or
unsupported transmission paths FAILS. The Exhibition documents what was
exhibited — it is not a census of what was industrially possible.
