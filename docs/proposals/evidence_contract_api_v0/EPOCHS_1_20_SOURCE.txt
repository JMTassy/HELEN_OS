LULU:
The user problem is not “decide whether a statement is true.” It is:

Given a typed claim and a finite submitted evidence package, determine the strongest warranted classification without converting attribution, absence, contradiction, or operator action into proof.

ZACK:

B=(r,\rho,\nu)

* r is one finite request;
* \rho is the resolver environment;
* \nu is the verifier family.

\text{Assessment is bounded to the submitted request and evaluator environment.}

A claim has one supporting submitted witness, but an unknown contradictory witness exists elsewhere.

Required result: the API may classify the submitted package as supported, but must not claim exhaustive or universal truth.

GAIN:
Ambiguity decreases by separating bounded assessment from global truth. Implementation burden is unchanged.

THEORY:

Typed Admissible Projection Theory

Given one typed claim-centered request:

r=(c,W,P,D_0),

evaluated under resolver \rho and verifier family \nu, construct:

\Pi(r;\rho,\nu)=(S,N,A,Q,D).

Where:

* S: presence of admissible direct support;
* N: presence of admissible direct contradiction;
* A: presence of authenticated reports;
* Q: presence of authenticated explicit hypotheses;
* D: set of authenticated operator-decision kinds.

A witness is admissible iff:

Adm(w,c)
\iff
Reachable(w)
\land
Verified(w)
\land
Relevant(w,c)
\land
TypeCompatible(w,c).

Relevance is exact claim-scope equality:

Relevant(w,c)
\iff
subject(w)=subject(c)
\land
predicate(w)=predicate(c).

For admissible witnesses:

polarity(w,c)=
\begin{cases}
SUPPORT & N_T(value_w)=N_T(value_c)\\
CONTRADICTION & N_T(value_w)\neq N_T(value_c).
\end{cases}

The theory classifies three independent axes:

1. evidence topology;
2. epistemic status;
3. operator disposition.

THEOREM:

Projection Sufficiency Theorem

For any two structurally valid assessments:

\Pi(r_1;\rho_1,\nu_1)=\Pi(r_2;\rho_2,\nu_2)

implies:

ASSESS(r_1;\rho_1,\nu_1)
=
ASSESS(r_2;\rho_2,\nu_2).

Therefore semantic output is invariant under:

* request item order;
* object-key order;
* duplicate multiplicity;
* serialization syntax;
* evaluator scheduling;
* resolver implementation;
* verifier implementation;
* diagnostic order;

provided the completed normalized admissible projection is equal.

Additionally:

PROVEN
\iff
S\neq\varnothing
\land
N=\varnothing.

Hence authenticated reporting, explicit hypothesis, operator action, witness failure, or evidence absence cannot independently establish PROVEN.

REFERENCE_ALGORITHM:

ASSESS(raw_request):
    validated := VALIDATE(raw_request)
    if validated is fatal:
        return {
            outcome: INVALID,
            epistemic_status: null,
            evidence_state: null,
            operator_disposition: null
        }
    witness_results :=
        MAP_INDEPENDENT(EVALUATE_WITNESS, validated.witnesses)
    provenance_results :=
        MAP_INDEPENDENT(EVALUATE_PROVENANCE, validated.provenance)
    decision_results :=
        MAP_INDEPENDENT(EVALUATE_DECISION, validated.decisions)
    WAIT_UNTIL_ALL_COMPLETE
    projection :=
        IMMUTABLE_PROJECT(
            witness_results,
            provenance_results,
            decision_results
        )
    evidence :=
        CLASSIFY_EVIDENCE(projection.S, projection.N)
    epistemic :=
        CLASSIFY_EPISTEMIC(
            evidence,
            projection.A,
            projection.Q
        )
    if cardinality(projection.D) > 1:
        return {
            outcome: HOLD_FOR_OPERATOR,
            epistemic_status: epistemic,
            evidence_state: evidence,
            operator_disposition: null
        }
    disposition :=
        unique member of projection.D
        if cardinality(projection.D) = 1
        else null
    return {
        outcome: ASSESSED,
        epistemic_status: epistemic,
        evidence_state: evidence,
        operator_disposition: disposition
    }

Witness evaluation:

EVALUATE_WITNESS(witness, claim):
    bytes := RESOLVE(witness.locator)
    if resolution fails:
        return REJECTED(UNREACHABLE)
    observed := VERIFY(
        witness.verifier.kind,
        bytes,
        witness.verifier.expected
    )
    if verification fails:
        return REJECTED(verification_error)
    if observed.type != witness.observation.value_type:
        return REJECTED(TYPE_MISMATCH)
    if scope(witness.observation) != scope(claim):
        return REJECTED(IRRELEVANT)
    if observed.type != claim.value_type:
        return REJECTED(TYPE_MISMATCH)
    if NORMALIZE(observed) = NORMALIZE(claim.value):
        return ACCEPTED(SUPPORT)
    return ACCEPTED(CONTRADICTION)
