## 0. Chiddush

TEMPLE stops asking first: *"What does this symbol mean?"*

It asks instead: *"Does this declared transformation conserve its structure
when it becomes trace, voxel space, and rhythm?"*

```
source → common trace → drawing
                      → voxel
                      → percussion
```

The same symbol must remain locatable in all three projections. Selecting a
letter must light up its point (drawing), its cells (voxel), and its sound
event (percussion).

## 1. Law

```
intermodal agreement = projection fidelity, NOT metaphysical truth
```

- A **convergence** across projections proves that the transformation chain
  is faithful. It proves nothing about historical intention, cosmology, or
  efficacy.
- A **divergence** localizes the first defective transformation in the
  chain — it is a debugging signal, not a spiritual verdict.
- The **voxel** projection is a spatial debugger.
- The **rhythm** projection is a humanly reproducible checksum: an operator
  can clap it back and compare without instrumentation.

This is the Garden law **DREAMT ≠ CLAIMED** applied to symbolic form:
TEMPLE may transform anything, but every transformation must remain
traceable, and no expressive power becomes sovereign by itself.

## 2. Operator pipeline

```
Gate → Load → Compress → Engine → Display → Fill → Seal
```

| Stage | Does | Does NOT |
|---|---|---|
| Gate | admits a source into the TEMPLE session (provenance recorded) | admit anything into the kernel |
| Load | ingests source bytes, hashes them | interpret |
| Compress | normalizes to the intermediate representation (see SIGIL_FORM_COMPILER_V0) | discard ambiguities silently — they are logged |
| Engine | computes coordinates, graph, projections | rank meaning |
| Display | renders drawing / voxel / rhythm with cross-links | claim equivalence beyond declared mappings |
| Fill | operator annotates, flags divergences | auto-promote annotations |
| Seal | emits a **TEMPLE replay packet** | emit a kernel receipt |

**The Seal is not a kernel receipt.** The replay packet contains: source +
hash, mapping version, transformation list, declared ambiguities, and the
fingerprint (sha256 of canonical JSON) of each projection. `authority:
false`, `ledger_effect: none`, always. If a TEMPLE result is ever worth
admission, it travels the ordinary road: structured proposal → obligations →
attestations → reducer → ledger.

## 3. Historical corpus discipline

The motivating corpus (Yemenite practical kabbalah, Judeo-Arabic amulets,
Coptic magical papyri, Liber Loagaeth, Sefer Raziel, Hebrew grimoires)
shows a recurring component inventory: letter squares, number squares,
hexagrams, wheels, name lists, anthropomorphic figures, symbolic animals,
point-to-point paths, writing sequences. An abstract scheme repeats:

```
Intention → sacred name → normalization → alphabet → grid → path
          → figure → support → action
```

with the *support* varying (drawing, seal, embroidery, chant, rhythm,
knocking, dance, talisman) while the structure stays largely stable.

Strict epistemic discipline, non-negotiable:

```
historical source        → attested description
modern interpretation    → declared as interpretation
computational architecture → testable hypothesis
```

Never conflate:

- formal resemblance ≠ proven historical transmission
- repeated structure ≠ universal intention
- modern projection ≠ ancient translation

The "universal sigil grammar" is a **research hypothesis** — compatible
with the observable resemblances, to be demonstrated historically, never
presumed. Corpus material itself (name tables, formulae, squares) enters
only through `helen_os/knowledge/symbolic_sources/` under the T4/T6
source-provenance floors; this proposal deliberately contains architecture,
not corpus data.
