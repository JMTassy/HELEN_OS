## COLOR GRAMMAR — CANDIDATE canon for UI, receipts, Garden, memory

Color encodes STATE CLASS, never decoration:

    ⚪ UNKNOWN     no promotion yet; open question, missing evidence
    🔵 OBSERVED    source exists ("we have a source" ≠ "it is true")
    🟣 INFERRED    S ⊢ C; derivation, synthesis — never silently
                   becomes blue or green
    🟡 PROPOSED    candidate ∉ Γ_admitted
    🟢 ADMITTED    C(δ)=1 under THIS governance regime — not
                   metaphysical truth
    🟠 HOLD        🌿(x) ⟹ no append ∧ no kernel mutation
    🔴 DENY        C(δ)=0 (variants: 🔴≠ contradiction · 🔴🛡️ safety ·
                   🔴👑 authority denied)
    ⚫ RESTRICTED  known ∧ ¬disclosable — orthogonal wrapper
                   (⚫🟢 = admitted but sealed); ⚫ ≠ ⚪

State machine:  ⚪ → 🔵 → 🟣 → 🟡 → {🟢, 🟠, 🔴}
Governing sentence:  🔵 → 🟣 → 🟡 → ⚖️ → {🟢, 🟠, 🔴}
Constitutional invariant:  💭 ⇏ 📜
