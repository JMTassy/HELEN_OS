## The extraction

Every witnessed border page confirms the same decomposition. A specimen
is not a picture; it is a generator:

    B = (g, τ, ρ, κ, σ, λ)

g a primitive glyph (rosette, meander unit, fleur-de-lis, disc, droplet,
spiral); τ the translation/repeat operator along an edge; ρ the
rotation/reflection rule at edge turns; κ the corner-transition operator
(visibly distinct corner units on Nos 213-230); σ the point size (the
pages sell the SAME glyph at 12/18/24 pt — σ is a free parameter, priced
per foot); λ the rendering layer. The catalogue's own commerce proves the
grammar: ATF sells g by the running foot, not B by the picture.

    GLYPH + TRANSFORMATION RULE → STRUCTURE — not a library of pictures.

## OPEN / TINT — the duality, now witnessed

Page 727 pairs every Art Border in two phases: No 5 Open / No 5 Tint,
No 7 Open / No 7 Tint — same topology, inverted occupancy, and the header
states they register as the two plates of a two-color print:

    g = (g⁺, g⁻),    I(g) = figure/ground inversion,    g_OPEN ⇄ g_TINT

A semantic unit therefore carries Ψ = (identity, topology, orientation,
phase, fill, scale) and remains ITSELF under permitted transformations.
For WUL: a symbol need not have one visual realization — much closer to
a visual language than emoji substitution.

## The strongest signal — the border as type annotation

The printer's border exists to declare OUTSIDE | INSIDE. HELEN already
runs on exactly that declaration: candidate|admitted, Garden|Kernel,
context|claim, unverified|verified. So the boundary itself can carry
machine-readable semantics:

    ∂X = β(X)   — the border of X encodes the governance state of X
    β_A ≁ β_B  ⟹  transition A→B is FLAGGED

**HELEN-side correction (binding on any use of this chiddush):** the
incompatibility rule may FLAG, never GATE. The border renders a state
that already has a receipt; only HAL/MAYOR make a transition
inadmissible. Border grammar is lint, not law. Constitutional line:

    rendering ≠ authority · representation ≠ admission ·
    glyph ≠ receipt · chiddush ≠ canon

A beautiful border can represent VERIFIED, RECEIPT, HOLD, GARDEN,
REPLAY; it cannot create that state.

## Role equivalence without visual identity

The witnessed pages show dozens of visually unrelated borders (Greek
key, chain, daisy, zigzag, droplet, spiral, Manila rope) all performing
one structural role — enclosing a rectangular semantic region:

    [g]_BOUNDARY = { gᵢ : Role(gᵢ) = BOUNDARY },  g₁ ≠ g₂ ≠ … ≠ gₙ

WUL gains **semantic equivalence without visual identity** — HELEN can
communicate by topological invariant rather than fixed glyph string.
This is the original WUL objective, found sitting in a 1902 catalogue.
