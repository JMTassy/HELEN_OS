## The rules — apply-ready, grouped by axis

| axis | best practice (implementable rule) | anchor |
|---|---|---|
| **hierarchy** | **One idea per slide.** If a slide makes two points, split it. The headline states the single idea; the body proves it. | Apple event summaries |
| **narrative** | **Problem → Solution → Proof arc.** No slide exists without an explicit link to the next. If a slide doesn't advance the argument, cut it. | Linear pitch deck |
| **titles** | **Slide title = the assertion, not the topic.** "Revenue grew 3× in 12 months," not "Revenue." Strip descriptive labels; make every title a claim or an action. | strategy decks |
| **data-viz** | **Data density over decoration.** A chart must be legible at 100% scale with no simplification; remove chart-junk, not data. | Palantir update |
| **color** | **Lock the color system before designing slides.** A fixed Primary·Neutral·Accent set dictates every element; decide it once, never improvise per slide. | brand guidelines |
| **typography** | **High-contrast headlines.** Type readable in a low-light room, from the back — size and weight, not cleverness. | Perplexity ads pitch |
| **pacing** | **Progressive disclosure + rhythm breaks.** Reveal sequentially (build complex slides), and punctuate with high-impact full-bleed visual beats to reset attention. | keynote pacing |
| **cover** | **Title slide as mood-setter.** The cover image evokes the emotional state of the *action you're asking for* — not a generic logo lockup. | editorial covers |
| **consistency** | **Consistency audit.** Identical iconography, button/label styles, and margins across every slide and category. One deviation reads as an error. | brand guidelines |
| **modularity** | **Every slide standalone.** It must hold visual integrity if screenshotted alone (decks get forwarded slide-by-slide). | portfolio logic |

## The insight that matters most — deck density is MODE-dependent (validator value-add)

The swarm surfaced a real tension: Apple/Linear favor **airy, one-idea slides**, while the MØRNING/Palantir
*reports* favor **dense information architecture, utility over whitespace.** Both are correct — for
different modes. **Do not average them.** The rule is:

| deck mode | density | primary discipline |
|---|---|---|
| **Investor pitch** | **airy** — one idea/slide, big type, breathing room | narrative arc + title-as-assertion + emotional cover |
| **Internal report / data room** | **dense** — utility-first IA, legible-at-100% charts | data density + consistency + slide-standalone |
| **Brand guideline** | **systematic** — locked system, exhaustive | consistency audit + locked color system |

For an **investor pitch deck specifically**: airy > dense, `Problem→Solution→Proof`, every title an
assertion, one emotional cover, and a proof slide (traction/numbers) that reads at 100% with zero chart-junk.

## Validator flags (opinion / heuristic, not law)
- 🟠 *"one visual break every THREE slides"* — the **principle** (rhythm breaks reset attention) is sound; the
  fixed count is arbitrary. Use rhythm by *section*, not a slide counter.
- 🟠 *"dense IA, utility over whitespace"* — correct for reports, **wrong for pitch**. Mode-gate it (see table).
