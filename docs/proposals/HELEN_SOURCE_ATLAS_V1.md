## 1. Core visual principle

HELEN OS is no longer a flat dashboard. It is a **layered source field** — a living
commentary-space: Talmud page × memory palace × semantic voxel cathedral × source
cockpit. **UI as layered intelligence field, not UI as screen.**

```
OLD                          NEW
dashboard / panels      →    source-as-world
pretty interface        →    commentary-as-orbit
                             proof-as-architecture
                             memory-as-3D terrain
                             choice-as-branching path
```

Composed of: medieval cosmology + Talmudic commentary page + cybernetic HUD +
high-dimensional memory map + strict receipt governance.

## 2. Canonical name

**HELEN OS SOURCE ATLAS** — "source first, spatialized, navigable, not decorative."
(Alternates considered: Source Atlas · Chiddush Atlas · Talmudic HUD · Memory
Cathedral · No-Claim Garden Interface.)

