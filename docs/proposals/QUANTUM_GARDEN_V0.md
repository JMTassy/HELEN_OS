## 0. What this is — and what it is not

Quantum Garden is a **renaming/formalization layer over the Garden that already
exists** in the HELEN stack. It adds no new firewall and no new authority path.
It gives the authority-zero exploratory field a state-vector metaphor and a
resource-weight vector, and it *polices that metaphor* so "quantum" never leaks
into a claim.

```
"quantum" here is STRUCTURAL METAPHOR, not a physical substrate claim.
No quantum hardware, no quantum measurement, no quantum advantage is asserted.
Rhetorical notation ⊬ measurement.  (the CHRONOS lesson, kept.)
```

If a real quantum substrate is ever present, that is a separate, evidenced claim
with its own witnesses — not this document.

## 2. Metaphor mapping (structural only)

| quantum term | Garden meaning | guard |
|---|---|---|
| superposition | many bounded hypotheses coexist pre-admission | coexistence ⊬ truth |
| interference | competing constraints reinforce/cancel search directions | not physical interference |
| measurement | a bounded experiment or witness acquisition | measurement ⊬ admission |
| collapse | a **local experimental outcome**, not truth | collapse ⊬ TrueWorld |
| decoherence | a branch loses coherence under evidence/contracts | not a physical process |
| entanglement | coupled hypotheses share dependencies | dependency ⊬ joint truth |
| amplitude `αᵢ` | **search weight / attention budget** | `αᵢ` ⊬ confidence, ⊬ probability-of-truth |

## 3. The state vector — and its single load-bearing guard

```

  αᵢ     a RESOURCE / SEARCH coefficient — how much attention budget the branch holds

**The one law that keeps this honest:**
```

    search weight ≠ truth probability
    branch survival ≠ admission
```
This is the same non-promotion law as ETA V0.1 §9 (`confidence ⇏ truth`,
`repeated proposal ⇏ admission`) and the L2 persona `DEFAULT_EPISTEMIC_STATE:
CANDIDATE`. If `αᵢ` were ever read as confidence, Quantum Garden would become a
laundering device — that is the failure mode this doc exists to forbid.

```
