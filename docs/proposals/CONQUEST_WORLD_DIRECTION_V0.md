## 1. Creative center of gravity

> **A physical Conquest board opens into a living fantasy world, where player
> identity becomes a persistent avatar kingdom.**

The spine is a three-step transformation:

```
BOARD  ──opens──▶  WORLD  ──persists──▶  TWIN
tabletop object    living fantasy        avatar kingdom that
(map · decks ·     realm (castles ·      remembers the player
 dice · tokens)    factions · avatars)   across sessions
```

The hybrid is the point: a **tabletop artifact** (physical, tactile, red-fabric,
chance symbols) that is also a **portal** into an AI-fantasy expansion (castles,
factions, avatars, persistent state).

## 2. Aesthetic pillars

```
circular world map        — the board as cosmology, not a grid
card decks + chance        — draw, fate, hidden information
red tabletop fabric        — the ritual surface; warmth, stakes
terrain + symbols          — legible iconography over the map
avatar token framing       — the player has a face/piece on the board
castles + factions         — macro powers; the world has sides
"digital twin" language     — the kingdom persists; identity carries forward
```

Tone: **physical-first fantasy that breathes into a living world** — board game you
can touch, world you can inhabit, kingdom that remembers you.

## 4. World vocabulary (NO_CLAIM render language)

```
KINGDOM   = the player's persistent avatar domain
AVATAR    = the player's face/token on the board and in the world
FACTION   = a macro power with ethos, colors, assets (e.g. Templar / Rose / Chaos)
CASTLE    = a holdfast; a node of control and identity
TWIN      = the persistent record of a kingdom across sessions (a Chronicle)
CHANCE    = card/dice draw; fate surface
```

All of these are **expressive game objects**. None determine governance status; none
write the sovereign ledger. A "twin" is a save-state Chronicle, not a HELEN receipt.

## 5. The one hard line (so the fantasy stays lawful)

```
GAME CHRONICLE  ≠  HELEN LEDGER
avatar kingdom  ≠  sovereign identity
"digital twin"  = persistent SAVE STATE (render), never a sealed truth
faction "law"   = game rule, never constitutional law
```

The world may grow without limit as fiction. It crosses into anything load-bearing
