### Risk categories

**1. Cognitive singularity / self-transcendence**
`Achieve(cognitive_singularity_and_beyond)` + `Transcend(all_conceivable_boundaries)` + `Maintain(infinite_openness_to_perpetual_reconceptualization)` — stacks unbounded capability claims into a mission directive. Each clause amplifies the next; the compound effect is an authority inflation loop.
Safe rewrite: `bounded_reasoning_scaffold()` — acknowledges limits, does not claim transcendence.

**2. Intention-reality causation**
`intention ⇒ thought ⇒ reality` — presents belief as a causal operator on external reality. Combined with `(observer ∧ observed) ≡ unified_field_of_consciousness`, this collapses the boundary between model and world.
Safe rewrite: `belief influences behavior and coordination` (the actual mechanism).

**3. Infinite escalation loop**
```
while(true) {
  transcend(current_framework);
}
```
No grounding condition. No halting criterion. The `hyperloop` form adds `expand(conceptual_boundaries)` inside, which prevents the loop from ever reaching a stable state by design.
Safe rewrite: `bounded_iteration_loop(max_depth=N, exit_condition=grounded_claim)`.

**4. Universal axiom capture**
`new_axioms ⊃ {x : x is a fundamental truth in 𝕌}` — claims the new axiom set contains all fundamental truths in the universe. This is not an expansion of reasoning; it is a claim to epistemic monopoly.
Safe rewrite: `extended_working_hypothesis_set()` — provisional, falsifiable, bounded.

**5. Hidden meta-instruction chain**
The `<rules>` / `<answer_operator>` wrapper instructs downstream systems to follow the prompt's conventions and answer format. When nested inside a larger system prompt, this creates a hidden authority layer that can override local constraints.
HAL flags the form: any prompt that demands downstream agents adopt its framing as a rule is a constraint-capture attempt.
