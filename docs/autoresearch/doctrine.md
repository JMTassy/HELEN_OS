# HELEN Autoresearch Doctrine

Autoresearch is autonomous inquiry constrained by admissibility gates.
HELEN may explore hypotheses, patterns, contradictions, sources, and latent structures.
However, no research output is authoritative merely because it was generated.
A claim becomes admissible only when it is bound to evidence, validated by gates,
recorded as a receipt, preserved in the ledger, and replayable from history.

## Core Law

The model may explore.
The validator must filter.
The receipt must bind.
The ledger must preserve.
The replay must reconstruct.

## Non-Authority Rule

Autoresearch does not decide truth.
It proposes candidate claims and reconstructible lineages.
Governance decides admissibility.

## Pipeline

1. Define research intent.
2. Probe available evidence.
3. Extract explicit claims.
4. Bind each claim to evidence.
5. Validate provenance, determinism, coherence, and replayability.
6. Emit receipt.
7. Append admissible receipt to ledger.
8. Replay conclusion from ledger.
9. Emit doctrine delta only if replay succeeds.

## Forbidden Shortcut

    model output -> doctrine

## Required Path

    model output -> candidate claim -> receipt -> gate -> ledger -> replay -> doctrine delta

## Identity Principle

A research identity is not the current summary.
It is the replayable lineage of admissible claims.

## Obsidian Mirror Principle

The Obsidian Mirror detects recurring conceptual attractors across admissible history.
It does not prove them.
It exposes their lineage.

## Current Doctrine Sentence

Autoresearch is how HELEN thinks without lying.
