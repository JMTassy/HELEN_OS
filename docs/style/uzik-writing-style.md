# UZIK writing style

Source of truth: UZIK direct observation — website, Drive presentations, planning docs, email attachments.

---

## DNA

short · structured · labeled · non-explanatory · production-oriented · visual-first · no rhetorical tricks · no persuasion

---

## Core rules

**Block writing**
Prefer blocks over sentences.
One idea = one line.

**Label-first**
Use tags instead of explanations.

```
CLIENT: GOOGLE
PHASE: PRODUCTION
FORMAT: EVENT / CONTENT FACTORY
STATUS: V2
```

**Zero justification**
Never explain why something is good.
Never argue. Never position.
Show work, categories, and status. That's it.

**No narrative flow**
Avoid paragraphs unless strictly required.
Break everything into lines.

**Visual thinking**
Write as if text will sit next to an image.
Text = support, not center.

**Compression test**
Before shipping: can this be cut in half?
If yes — cut.

---

## Vocabulary

Use:
- craft
- cultural resonance
- category tags (Brand Content / Social Media / Influence / Strategy / Event)
- phase labels (conception / pre-production / production / exploitation / post-mortem)
- versioning (V0 / V1 / V2 / V3)
- ownership lines (UZIK / GOOGLE / CLIENT / OPERATOR)

Do not use (agency clichés, banned for HELEN/system copy):
- innovation
- impact
- excellence
- AI paragraph soup
- rhetorical persuasion patterns

---

## Default structure (when structure is needed)

```
CLIENT
PROJECT
CATEGORY
PHASE
STATUS
NEXT
```

Or for longer pieces:

1. Context
2. Objective
3. Proposal
4. Production logic
5. Validation
6. Next action

---

## Headline logic

Short. Declarative. No explanation layer.

Good: "Shaping the new standards for iconic brands"
Good: "Brand Content / Social Media / Strategy"
Bad: "We help brands achieve meaningful impact through innovative content strategies."

---

## What this is not

Not an essay. Not a chatbot answer. Not a LinkedIn post.
A studio deck. A production label. A status line.

**D.N.A. four-beat** (the order UZIK describes itself in):
MODE DE TRAVAIL (Conseil + Factory) → MÉTIER (Brand Experience 360) → PASSION (le craft) → FORCE (UZIK Family / réseau)

**Headline register:**
- Declarative first-person-plural: "WE …"
- Bilingual EN / FR, one punchline per surface.
- NO bullets on brand surfaces (2018 anti-bullet law) — the image carries the rest.

**Culture-pop naming law:**
Names echo pop culture. Sourced examples: "Smart is the new cool" · "fifty shades of digital marketing".
Same phrase-key instinct as Calvi "ouvre ses portes" / ba&sh "open the doors".
