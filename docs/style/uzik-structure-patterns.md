# UZIK structure patterns

Operational grammar extracted from UZIK agency artifacts.
Status: DRAFT — enrich from Drive / Gmail as docs are pulled.

---

## Section naming conventions

Production phases (in order):
```
CONTEXT
OBJECTIVE
PROPOSAL
PRE-PRODUCTION
PRODUCTION
POST-PRODUCTION
VALIDATION
NEXT
```

Status markers:
```
V0 / V1 / V2 / V3
PENDING / READY / DELIVERED / BLOCKED
```

Ownership markers:
```
UZIK / CLIENT / GOOGLE / OPERATOR
```

---

## Slide pacing logic

Each block = one idea.
Each idea = 1–4 lines max.
No connective tissue between blocks.
White space does the work sentences would do.

---

## Timeline syntax

```
PHASE
Date or week reference
Owner
Status
```

Example:
```
KICK OFF
Tuesday 10:00
UZIK + GOOGLE
Confirmed
```

---

## Approval language

Minimal. Status only.
```
VALIDATION
GOOGLE — Pending
UZIK — Ready
```

No: "We are waiting for Google's feedback on the revised proposal before proceeding."
Yes: "GOOGLE — Pending"

---

## Production verbs (active, short)

Use:
- shoot / capture / edit / select / deliver / validate / brief / cast
- kick off / wrap / submit / review / approve / iterate

Do not use:
- leverage / optimize / synergize / enhance / showcase
- "we are excited to" / "we look forward to"

---

## French-English mixing

Switch when the French term is more precise or more natural for the context.

Common UZIK French terms in operational docs:
- bilan (post-mortem)
- brief (shared)
- tournage (shoot)
- montage (edit / assembly)
- livraison (delivery)
- validation (same in both)
- régie (production management)

Rule: French for internal operations, English for client-facing labels unless client is French.

---

## Escalation style

No alarm language. No urgency performance.

```
BLOCKER
Location access — TBC
Owner: UZIK
Status: Pending confirmation
```

Not: "URGENT: We still haven't received confirmation on the location access and this is blocking production."

---

## Deck rhythm pattern

```
Title line (1 line)

CONTEXT block (3–5 lines)

OBJECTIVE block (1–2 lines)

PROPOSAL block (V-numbered, 3–6 lines)

PRODUCTION breakdown (phase by phase)

VALIDATION block

NEXT block
```

No introduction. No conclusion. No "about us" unless asked.

---

## Compression test (applied to structure)

After drafting any block: read it aloud.
If it takes more than 5 seconds — cut it.
If it could be one label instead of a sentence — use the label.
