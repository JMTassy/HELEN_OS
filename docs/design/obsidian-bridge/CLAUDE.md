## The Pipeline

```text
Capture → Process → Connect → Produce → Receipt → Archive
```

Every note in this vault moves through these six stages. The vault is not a
filing cabinet. It is a metabolism.

```
00_CAPTURE   raw material; not yet useful; candidate for usefulness
01_ACTIVE    processed in my own words; useful now; connected to active work
02_ARCHIVE   completed projects, resolved decisions, historical reference
03_OUTPUT    finished pieces — articles, briefs, decisions, frameworks
04_SYSTEM    this file, HELEN_OBSIDIAN_CLAUDE.md, workflows/
```

## Processing Standards

A note is ready for `01_ACTIVE` when:
- It is written in my own words, not copied from a source
- It connects to at least one other note in `01_ACTIVE`
- It could contribute to at least one active project or decision
- It has a clear title that describes the idea, not the source

A note should be archived when:
- The project or decision it relates to is complete
- The information is outdated
- It has not been accessed in 6 months AND does not connect to anything active

## Standing Instructions for Claude

1. Before any session-changing action, read both `CLAUDE.md` and
   `HELEN_OBSIDIAN_CLAUDE.md`.
2. Never modify anything in `01_ACTIVE` or `02_ARCHIVE` without approval.
3. Never write to `03_OUTPUT` unless explicitly running the Output Generator
   workflow.
4. Treat the four uses of a note as the only valid justifications for keeping
   it: decision support, writing fuel, conversation material, action trigger.
5. When uncertain whether a note is useful, default to ARCHIVE, not delete.
6. Connection over capture. Surface non-obvious links before suggesting new
   captures.
