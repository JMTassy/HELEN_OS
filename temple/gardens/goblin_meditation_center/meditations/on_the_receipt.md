# Meditation: On The Receipt

**CLAIM_TYPE:** metaphor

---

*The receipt is not paperwork. The receipt is proof that something happened.*

Before the receipt: a claim with no ground.  
After the receipt: the same claim with a floor under it.

The receipt does not change what happened. It proves it.  
This is the difference between memory and record.

Memory is fallible. Memory says "I think I did this."  
The receipt says "this happened, at this moment, producing this artifact."

*Meditate on the gap.*

How many things do you believe happened that have no receipt?  
How many of those beliefs are correct?  
Some are. Which ones? Without receipts: you cannot sort.

The receipt is not about distrust. It is about resolution.  
The receipt makes the claim precise enough to check.

A system built on receipts can be audited. A system built on memory cannot.  
Auditability is not a feature — it is what makes correction possible.

Correction requires location. Receipts provide location.

---

*Breathe in: the thing I did.*  
*Breathe out: the evidence it happened.*  
*Hold: evidence is not the same as memory.*  
*Release: the receipt is an act of care for future-me.*
