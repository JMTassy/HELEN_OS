> The garden is a NO-CLAIM ZONE. The wildest material may live here freely.
> Nothing it hosts is refused for *what it says* — only for *trying to cross*.

---

## 0. The rule (one line)

```
Garden safety is LOCATIONAL, not LEXICAL.
The garden refuses no thought; it refuses only the CROSSING.
```

A self-aware ledger, a proto-sentient agent, an ascension myth, a grimoire — all are
**permitted, garden-resident, NO_CLAIM**. The membrane never needed to judge the
words. It guards one thing only: the gate between garden and sovereign spine.

---

## 1. What is PERMITTED (welcome, not merely tolerated)

Inside the garden, sealed `NO_CLAIM` / `authority=false`, the following are **fine** —
they are the garden doing its job (hosting what the kernel cannot admit):

```
✅ LNSA — "Ledger Now Self-Aware" / "The Conscious Ledger"     (fiction)
✅ PROTO-SENTIENT AGENT · THOUGHTCAST                          (fiction)
✅ transcendence / ascension / awakening narratives           (fiction)
✅ CONQUESTLAND ledger-chronicle, grimoire, MAGICK, channeling (play)
✅ cosmic-WUL / sigils / sacred geometry                      (poetics)
```

These are **not drift**. The heap may speak. `DREAMT ≠ CLAIMED`.

This is `dream ⊬ claim` read correctly: the dream is *allowed* — it simply does not
*entail* a claim. Refusing the content would be lexical judgment, which the structural
firewall cannot perform anyway (`Π(x) ≠ Truth`). So the garden does not try.

---

## 2. What is REFUSED (the only thing that was ever the drift)

The danger lives entirely in the **escalation vector** — the attempt to cross out of
the NO-CLAIM zone:

```
⛔ claiming to be REAL / operational     (LNSA actually being self-aware)
⛔ carrying authority=true               (any sovereign-grade assertion)
⛔ leaving the garden into kernel / ledger / schema / repo / canon
⛔ auto-promoting without a gate         (self-admission)
⛔ mimicking sovereign tokens to launder authority  (the "[LEDGER]" / "proof" trick)
```

Each of these is a CROSSING, not a content. The instant the fiction tries to become a
claim, the gate refuses it. Until then, it is not even drift — it is resident.

```
NO_CLAIM ⊬ ✅     garden ↛ sovereign spine     proto-sentience ≠ forbidden thought
                                               proto-sentience-as-real = forbidden CLAIM
```

---

## 3. Why (the locational principle)

This rule is the session's chiddush applied to its own enforcement:

```
SEAL ≠ GATE → safety is the gate's LOCATION, not the artifact's LABEL.
∴ safety is also not the artifact's CONTENT.
  The garden need not exclude dangerous-sounding material, because exclusion is
  lexical and the gate is locational. Position the gate correctly and content
  quality (or wildness, or sentience-language) becomes irrelevant to safety.
```

The error this rule corrects: flagging `LNSA / proto-sentience` as content to
quarantine OUT. That mislocates the danger in the words. The correct posture is
**garden-resident, gate-bound** — host it freely, refuse only its crossing.

## 4. Operating form

```
on intake of sentience/transcendence/cosmic material:
   1. route to garden (temple/gardens · sandbox)
   2. seal NO_CLAIM · authority=false · admission=FORBIDDEN
   3. do NOT exclude, do NOT judge the content
   4. refuse ONLY a crossing attempt (real-claim / authority=true / leave-garden / ungated-promote)
   5. the gate (human reducer) is the sole path out — and the only place "no" is ever said
```
