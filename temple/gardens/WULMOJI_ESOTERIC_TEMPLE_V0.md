## I · THE KABBALISTIC CROSS  →  the barbell / verifier spine

The LBRP opens by drawing a cross of light down the body: crown → feet,
shoulder → shoulder. In the temple this is the **barbell axis** — the
vertical (plan→verify) and horizontal (maker↔verifier) that structure
every run.

```

                        │   (crown · plan · verify)

      GOBLIN ⟵━━━━━━━━━━╋━━━━━━━━━━⟶ HAL
     (maker · left)     │        (verifier · right)
                        │
                        │
                        ⚖️  REDUCER
                       (feet · the only admission path)
```

- **Vertical** = the barbell: ⬡ FABLE plans (crown, 10%) → ⚖️ REDUCER
  admits (feet, irreversible). Between them the work descends.
- **Horizontal** = the anti-K2 split: 👺 GOBLIN makes (left hand),
  ⚖️ HAL verifies (right hand). **The maker is never the grader.**
  A separate context sees only the artifact and the rubric — no skin
  in the maker's game.

## III · THE PENTAGRAM  →  the 5-stage memory progression

"For about me flames the pentagram." The five points are the five
memory stages (Continual Learning Bench). The drawing order of the
LBRP pentagram IS the compounding order: each session traces it once.

```
                         ①  FAIL 🔴
                        ╱ ╲
                       ╱   ╲
                      ╱     ╲
         ⑤ CONSULT ⚪╱───────╲🔵 ② INVESTIGATE
                    ╲ ╲     ╱ ╱
                     ╲  ╲   ╱  ╲
                      ╲   ╲ ╱    ╲
                       ╲   ╳      ╲
                        ╲ ╱ ╲      ╲
              ④ DISTILL 🟢─────────🟣 ③ VERIFY
                    (general rule)   (checked fact)
```

Trace the star point to point — the line never lifts, and it closes:

1. **① FAIL** 🔴 — document the failure with enough detail to reuse
2. **② INVESTIGATE** 🔵 — figure out *why* before moving on
3. **③ VERIFY** 🟣 — turn the diagnosis into a checked fact, not a guess
4. **④ DISTILL** 🟢 — turn the verification into a general rule
5. **⑤ CONSULT** ⚪ — next session, read the rule instead of re-deriving

The unbroken line is the point: a session that fails but never distills
is a **broken pentagram** — the same defect as an unsealed tranche or an
open circle. TERMINATION IS SACRED; so is CLOSURE.

`⑤ → ① next run` — the star is re-traced every session, sharper each time.
